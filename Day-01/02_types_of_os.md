### Types of Operating System
Operating Systems (OS) are classified into different types based on how they manage processes, users, tasks and computer resources.

### 1. Batch Operating System
*Executes a group (batch) of similar jobs without requiring direct user interaction during execution.*<br>
*Jobs are collected and processed one after another.*<br>
*Example: IBM OS/360.*

### 2. Multiprogramming Operating System
*Keeps multiple programs in memory simultaneously.*<br>
*When one program waits for I/O, the CPU executes another program.*<br>
*Improves CPU utilization.*<br>
*Example: OS/360*

### 3. Multitasking Operating System
*Allow a user to run multiple application seemingly at the same time.*<br>
*CPU switches between tasks rapidly.*<br>
*Examples: Window, Linux, macOS.*

### 4. Multiuser Operating System
*Allows multiple users to access the same computer system simultaneously.*<br>
*Each user gets access to system resources.*<br>
*Examples: UNIX, Linux.*

### 5. Multiprocessing Operating System
*Uses two or more CPUs or processor cores to execute processes simultaneously.*<br>
*Improves performance and processing capacity.*<br>
*Examples: Linux, Windows, macOS.*

### 6. Multithreading Operating System
*Supports multiple threads within a single process.*<br>
*Threads share the same process resources but can execute independently.*<br>
*Example: Windows, Linux, macOS.*

### 7. Real-Time Operating System (RTOS)
*Processes data and responds to events within a specified time limit.*<br>
*Used where timely responses are critical.*<br>
Types:<br>
    *Hard Real-Time OS: Missing a deadline is unnacceptable.*<br>
    *Soft Real-Time OS: Occasional deadline misses are acceptable.*<br>
*Example: VxWorks, QNX, FreeRTOS.*

### 8. Distributed Operating System
*Manages multiple connected computers and makes them work together as a unified system.*<br>
*Resoureces and workloads can be shared across machines.*<br>
*Examples: Amoeba, Plan 9.*

### 9. Network Operating System
*Provides services to computers connected through a network.*<br>
*Supports file sharing, printer sharing, user management, and network security.*<br>
*Examples: Windows Server, Novell NetWare.*

### 10. Embedded Operating System
*Designed for dedicated devices that perform specific functions.*<br>
*Usually optimized for limited hardware resources.*<br>
*Examples: Embedded Linux, FreeRTOS, Zephyr.*

### 11. Mobile Operating System
*Designed specifically for smartphones and tablets.*<br>
*Manages touch interfaces, mobile applications, sensors, and wireless connectivity.*<br>
*Examples: Android, iOS.*


### Important concepts to understand
Some types are closely related, but they are not the same:<br>
**Multiprogramming vs Multitasking:**
*Multiprogramming focuses on keeping the CPU busy*<br>
*Multitasking focuses on switching between tasks to provide responsive execution.*

**Multiprocessing vs Multithreading:**
*Multiprocessing uses multiple processing units.*<br>
*Multithreading allows multiple execution threads within a process.*<br>

**Distributed OS vs Network OS:**
*A distributed OS aims to make multiple computers works as one system.*<br>
*A network OS provides services and resources sharing between independent computers.*
